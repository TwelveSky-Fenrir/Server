# ---------------------------------------------------------------------------
# Schema migrations (post-base-DDL, pre-seed). A change to a Tables/*.sql,
# Schemas/Types/*.sql, or StoredProcedures/*.sql script already listed above
# cannot be made by editing that base file -- DbMigrator SHA-256-journals every
# applied script and refuses to re-apply one whose content changed, so an
# in-place edit hard-fails the next run on any already-provisioned database.
# Additive schema evolution therefore lands here as a new, never-edited script
# that converts the base-created state to the target state: a fresh database
# applies base-then-migration, a persistent one skips the already-journaled
# base scripts and applies only the new migration -- both converge.
# ---------------------------------------------------------------------------
